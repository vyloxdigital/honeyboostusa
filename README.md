---------------------------------------------------
NOTES
---------------------------------------------------
- All images should be in .webp format for best performance
  (except favicon.png which must be .png)
- Compress images to keep file sizes under 100KB each
- Use a free converter at: squoosh.app or convertio.co
- If you don't have .webp versions, the website shows
  emoji fallbacks automatically — it won't break
